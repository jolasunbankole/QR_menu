# QR_menu
I'm studying Computer Systems &amp; DevOps, targeting Cloud Engineering. 
My project blends AWS with HTML, JavaScript, CSS, and Python: 
A QR code scanning app that redirects users to a coffee shop menu. 
Each order is instantly sent to the vendor(database) for preparation—streamlining the café experience using cloud-native tools and automation

For Testing, I will be using Docker

For deployment, I will use AWS services
